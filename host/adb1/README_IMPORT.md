# ADB1 配套上位机来源

本目录的八个 Python/依赖文件最初取自用户提供的 `ADB1_SWM4_ADC64_V2_Qualified_20261029.zip` 的 `host/`，导入时与包内 `MANIFEST.json` 的 SHA256 逐项校验一致。此后 `protocol.py` 的手势文案已更新，与 DownStop 新包同名文件字节一致，SHA256 为 `cb2183064754eb5aad8855ac97fef3e441667d4ee4c0489b6e406bd26c302548`；其余七个文件保持原样。由仓库原有的 `START_HOST.bat` 选择 6 启动，默认是原 Host 的离线演示；要连接真实 USB 需由用户在 ADB1 窗口明确填写串口并连接。复用 FD2 随包的 pyserial 3.5，通信和保活仍由 ADB1 原版 SerialOwner 管理。

2026-10-30：桌面窗口手势文案已按 DownStop 版更新：下滑 STOP，挥手无动作。使用此文案须确认已烧录 DownStop 位流；新旧固件共用身份，不能通过身份自动区分，旧版的挥手 STOP 行为不会随上位机更新而改变。

ADB1 窗口通过本机 8371 桥向展示网页提供状态和波形。网页可显式发起 SWM4 起摆、手动平衡、STOP/ESTOP、校零、清故障以及自适应开关，均由同一个 ADB1 串口所有者执行；ACK 只表示请求结果，超时不重发。其他操作仍可在配套窗口中进行。离线模拟禁止网页硬件命令。不要同时打开两个 Host 占用同一串口。它只支持 SWM4，不支持 SA21/144；固件身份为 41444231 / 41444203。离线演示在网页标明「离线模拟」，不代表实物数据。本适配没有烧录固件或实机验证。

2026-10-30：根据现场日志，板端时间和遥测序号持续前进时，控制事务 epoch 会重新从 1 开始。外层桥在身份已核验且时间、序号均向前时重新建立 Host 控制历史基准，保留原始会话日志与桥波形历史，并在波形标记不连续；不接受旧序号或旧板时帧。该修复已用现场日志中的重置片段离线检查，尚待现场复验。
