DS13 · R2 手绘版（2026-11-03）

完整解压后，双击本包最外层的“打开手绘窗口.cmd”。
正常标题：J280 手绘控制 · DS13 · R2。
未连接设备也应看到左“手绘”、右“实际”两个图区；旁边的PNG是正常界面示意。
DS13_App目录保存运行环境、源码和证据，日常使用从最外层启动。

R2修复内容
1. 目标点按20ms节奏采样发送，回执独立处理；不再发完每一个点后等待它的回执。
2. 使用结果一致的原生CRC计算，减少解码耗时。
3. 绘图区只提取新收到的数据，鼠标事件不再触发整张历史曲线重画。
4. 保留连续连线、右侧真实编码器数据、断流空隙；不伪造实测轨迹。
5. 明确指定包内Python/Tk与手绘程序，窗口按桌面大小调整。启动报错记录在DS13_App/startup_error.log。

窗口默认不连接、不自动写参数、校零或启动。
连接后按原操作校零、启动平衡，再按住左图绘画；松开结束本笔。
若显示“故障01”，这是板端角度保护：扶回此前校零的直立位置，点“设置 → 清除故障”，再点“平衡”。

平衡和位流没有变化，本机已经是DS13则不用重烧。
角度P/I/D：53.78 / 0 / 210.14，P1ms / D5ms。
位置P/I/D：17.67 / 0 / 616.61，P5ms / D25ms。
ADC64点/1ms，位置滤波732284/2^24。完整精确参数见DS13_App/S1参数.json。

源码：DS13_App/V5/project/forest_d1_v5.gprj及src；上位机源码：DS13_App/host。
位流：DS13_App/firmware/J280_DS13_S1_LIVE.fs。
器件GW2A-LV55PG484C8/I7，50MHz，DS13身份44533133/schema44535002。
给其他板子下载时使用Gowin Programmer的GW2A-55C/SRAM Program；软件与驱动另装。
SRAM下载断电不保留。R2没有重新编译或操作板子，源码与位流逐文件确认和之前DS13相同。

核验范围
19项上位机回归通过；1000组CRC比对一致；250ms点回执延迟测试通过。
旧发送方式在该延迟测试中出现断流，R2连续3秒发送140点未断流。
4万条曲线和历史数据持续绘图30秒，发送1143点，未断流、未报通信错误。
这是本机软件模拟检查，不等于已经在队友电脑或其机械装置上完成验收。
原DS13布线后Fmax54.97MHz，setup/hold违规端点0；本次沿用相同位流。
