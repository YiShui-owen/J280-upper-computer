# DS13 原始 Host 来源

日常版本为 `releases/20261103_r2/DS13_App`，完整解自 `J280_DS13_手绘窗口_R2_完整包_20261103.zip`。原 ZIP SHA-256 为 `ff224d58fa9a3052f4440c750f0f6862f17cbf2f61fd038336b19b820e9bcd0f`；外层清单中的 2224 项已逐项验证并按原字节保存，完整报告和运行时随包保留。位流 SHA-256 为 `677b66bdd36c9ceb49ffb6ac813e1acd9042e6f7db922208fd27969a90d067e7`，与原 DS13 位流一致。

R2 原 Host 以约 20ms 节奏发送最新目标，独立处理点回执；`host/ds13_bridge.py` 保留独立浏览器租约、会话绑定、取消和过期保护。网页移动输入按约 30ms 更新，续租不等待旧回复；后端仅复用短时间内、与当前配置匹配的已核验状态，过期后仍需重新核验。桥分页按游标读取，避免每次扫描整段历史。网页底部的目标与实际以同一笔画原点和板端笔画时间显示；目标按原 Host 的目标更新点连线，实际只来自编码器，缺帧处断线。原 Host 的 R2 改动与其报告保留在随包目录，外层桥不是队友原版的一部分。

`upstream/host` 中 35 个文件直接从 `J280_DS13_S1平衡_现场手绘_队友包_20261103.zip` 解出，包括 vendor，未改动。ZIP SHA-256 和逐文件 SHA-256 见 `MANIFEST_SHA256.json`。外层适配位于 `host/ds13_bridge.py`，并非原交付的一部分。

运行 `START_HOST.bat` 选择 DS13 R2，原窗口负责显式连接；Host 窗口或网页均可按住左侧画图，同一时刻只有一个入口可以绘制。网页每次输入带时间戳，Host 以输入时刻限制 200ms 续租，松开或过期后迟到的笔画不得重新触发。桥不自动连接或执行动作。若旧版 Host 已在运行，需关闭并启动 R2 才能应用更新；关闭原 Host 会按其原逻辑尝试 STOP。真实硬件、方向和 R2 点流效果尚未在本项目验证。

从该入口打开的 DS13 窗口由外层 `host/ds13_theme.py` 应用与网页一致的深色配色；原始交付的窗口和控制代码保持原字节。配色适配只改变控件及曲线颜色，不改变窗口控制、绘图数据或串口行为。
