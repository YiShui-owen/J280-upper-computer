# 本包调参窗口

只配套本目录的固件，UserCode `53473231`，schema `53475421`。双击 `启动起摆调参.ps1`；连接前核对固件，窗口启动不会自动连接、写参数或起摆。冷启动PID仍为0。

1. 明确选择J280串口，连接后先STOP，等实际读回PWM=0、无运行会话。
2. 用“附件数值填表（不发送）”查看参考值，再按实际机台确认后显式提交整组。附件报告值为角度P/I/D900/870/90，位置P/I/D112/0/48，KI1、DF650、W5；这是已有参考，不是本轮实机标定结果。
3. 需要时显式标定零点，等零点有效；读取并按需调整两段起摆参数。默认前向49%/100ms、反向36%/220ms；力度1..90%，时间1..1000ms，STOP时修改。
4. 将“手势控制开关”设为1并读回，右滑可请求起摆。正式BALANCE后，顺/逆时针手势分别请求正/反一圈，每圈轨迹2秒，沿用加减速曲线；忙时不排队。左滑取消当前参考并保持，挥手走STOP路径。上/下/近/远及组合手势不发电机命令。
5. 挥手沿用官方识别等待，可能约1秒才发布事件，不能替代急停。紧急情况使用板上急停或窗口STOP。参数修改必须先停止，断开串口不等于停止电机。

保持原J280手势总线约束SCL=Y4、SDA=Y5，信号为3.3V开漏。U127模块输入为5V、公共地；不能把5V接到FPGA信号脚，也不能沿用ACG525的C17/C18针脚。本次未连接板卡核实实物接线或方向。

左滑在圈中途取消后，参考可能停在小数位置，原轨迹模块会拒绝下一圈；先STOP，再重新起摆或进入平衡后转圈。整圈结束后的连续正反圈不需要重启。
