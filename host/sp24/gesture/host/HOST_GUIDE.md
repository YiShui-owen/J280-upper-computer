# SP24 调参及手势状态窗口

只配套 J280 SP24 固件：UserCode `53503234`、schema `53505424`。双击 `启动起摆调参.ps1`；启动不会连接、写参数或运动。一个 Host 独占串口，CLI 只使用本机助手桥。冷启动 PID 为0、手势关闭、E关闭且配置无效。

## 同步波形与精确日志

连接后接收新的 `J2T4` 二进制遥测，标称100Hz，每帧80字节；115200/8N1下占约69.45%发送带宽。波形按约30帧/秒重绘，记录与绘图分开：窗口缩小也保留全部已接收的有效样本。按“放大波形”可打开独立大图，不发送任何控制命令。

三组曲线共用最近10秒的板端采集时间轴：测得摆角与角度参考（°）、测得旋臂与位置目标（°）、实际PWM（%）。旋臂纵轴使用明确标出的局部原点count，避免长时间多圈后浮点抵消丢掉Q32小数。旋臂换算为3count/°；编码器测量本身仍是离散count，没有提高硬件分辨率。摆角显示更细小数，也不代表ADC精度增加。

新帧中的摆角、速度、编码器、目标、角度参考及两个参数版本来自同一个已提交控制快照，时间为 `timestamp_ms`。PWM、mode、故障和保护位是 `capture_ms` 时刻的实时状态，不能把它们解释成此前PID运算时刻的数据。窗口分别显示“接收龄”和“PID样本龄”：前者是Host收到最后一帧后经过的时间，后者为板端采集时刻减去控制样本时间；都不是未经测量的USB端到端延迟。

角落显示实际到达/板时采样率、有效帧、缺帧、CRC错误、重复及重启/乱序次数。超过250ms未收到有效遥测显示“数据陈旧”。测得摆角和编码器在停机、PID未运行时仍可显示：Host观察到非初始化控制样本时间，且样本龄不超过10ms时，绘制真实测量快照；目标/参考还须PID有效。这个10ms是显示新鲜度判断，不是新增的FPGA测量有效位或控制保护。样本时间重复显示“测量保持”，不把重复快照延伸成新测量点，过期显示“测量快照陈旧”并停止延伸测量曲线。丢帧处显示红色虚线并断开曲线。板时32位回绕正常展开；序号或板时回退会开始新epoch并清空旧的实时视图，历史CSV仍保留各epoch，绝不虚构跨重启时间。图像按像素选首点、最小值、最大值和末点，保留窄尖峰，不插值、不平滑。

每次显式连接在 `sessions/<时间>/` 保存：

- `telemetry.csv`：同步帧全部原始整数、完整96位Q32目标、64位编码器/参考、序号、两个板时、Host时间、epoch、丢帧和状态位，以及精确换算列。Q32→count采用十进制高精度运算；原始列、十六进制列为最终依据。
- `samples.csv`：兼容原有角度/旋臂/阶段的低速独立查询，不能与同步帧混作同一控制时刻。
- `readonly.jsonl`：既有只读页4–9的手势、状态、自适应增益/积分与原始ACK；各页保留自身时间，仍非100Hz连续记录。
- `raw.bin` 和 `frames.jsonl`：接收字节、通过CRC/身份检查的原始帧及Host到达时间。JSON额外提供 `wide_integer_decimal` 字符串，供JavaScript等只能精确表示53位整数的读取端使用；不要把宽整数JSON数值或Excel自动转换后的数值当作完整96位值。CSV另存 `0x` 开头的64/96位补码十六进制列，便于避免表格软件损失整数精度。

CSV由独立线程批量写入，正常调度下每250ms刷新并在正常关闭时清空缓冲；原始/帧日志也按250ms批量刷新。强制结束程序或断电仍可能丢失尚未刷盘的末尾数据。CSV队列最多8192条；磁盘错误或持续阻塞会明确显示日志错误和未记录行数，不会静默声称记录完整。串口读等待缩短至10ms；STOP仍优先于尚未发送的请求，遥测不能确认或完成控制命令。

`reports/host/waveform_synthetic_display.png` 与对应PostScript用于离线绘图验收，图中数据明确为合成输入，不是实物测量；常规启动不会生成这些波形。本轮未接板，真实USB丢包率、实物帧率及操作到显示延迟仍待现场测量。

1. 显式连接 J280 的串口，先 STOP，等真实读回 PWM=0、无运行会话。旧 SP22/SA21 固件的身份会被拒绝。
2. “明确选择参数预设”页选择后仍不会写入；按“应用所选预设并逐项读回”才逐项写入。现场回读基线位置112/0/48，阻尼候选112/0/56，慢积分候选112/2/48；共同角度P/I/D900/870/90、KI1、DF650/W5，手势开启、E关闭。只读编码器模式1和位置D滤波578949194须先读回一致。位置候选尚未经过本轮实物验证；不承诺改善。另有角度D80候选900/870/80，以及角度I780候选900/780/90；它们分别相对现场基线只改一个角度增益，位置仍112/0/48，均保持E关闭。角度与位置六个PID增益都可在停止时显式调整；先固定角度比较位置，只是对照阶段，不是永久限制。六项预设含这两个角度分支与单独起摆设置；不自动组合候选。完整依据及换算见包内参数说明及双环调参计划。
3. 现场记录的起摆70%/230ms、反向70%/230ms、最多1次须单独选择应用。它不等于出厂默认49%/100ms和36%/220ms；窗口连接及断线不会自行恢复任何一组。反向计时包含减速和过零。
4. 按需要显式标零，等零点有效；再独立按 RUN，或者手势开启后向上滑请求起摆。右滑不会起摆。所有预设都不会自动标零、起摆、运行电机或启用E实际控制。
5. 从起摆接受开始，到所有SWM2阶段结束且实际 BALANCE/HOLD就绪前，所有手势（包括挥手）都丢弃，不会留待接管后执行。此间可继续看传感器事件，使用窗口STOP或物理急停停止。
6. 实际平衡就绪后，左/右滑启动对应方向相对定位；默认50°，停止时可调1..360°。转动中反向滑动取消当前位置参考并保持平衡；该次取消不反向启动，再次手势才开启下一段。同方向重复事件忙时忽略，不排队。方向映射可用“左滑对应负方向”调整。顺/逆时针各一圈、轨迹2秒。取消后可直接再次定位或转圈，不需STOP重入。
7. 平衡后挥手走STOP路径。传感器保留官方挥手约1秒等待，不能替代急停。下滑、靠近、远离及组合手势未映射为电机动作。

## 实时事件与拒绝原因

“手势 / 平衡后自适应”页显示最近实际手势、事件号、板端事件时间、动作和接受/拒绝原因。未开启、未就绪/通信错误、起摆忽略、尚未实际接管、HOLD未就绪、轨迹忙、保护拒绝、无映射、轨迹拒绝、等待确认分别显示。快照保留到下一事件；重复查询不算新事件，重连首次读到旧快照也不算新收到。

另行显示传感器ready、当前/累计错误、手势屏蔽、真实平衡许可、电机许可、零点、急停/故障、起摆阶段、交接请求、自动/手动会话、HOLD初始化和轨迹运行/忙。查询序号与事件号是两件事。页8/9交错查询；页面时间各自独立，不是1ms连续测量，也不能把过去事件和当前状态拼成同一时刻。页4原始寄存器仍保留在本机桥状态中。

## 自适应与预设资格

E只调整位置外环，复用原SA21运算和独立积分；不是自动辨识电机，也不能保证救活不稳定的角度环。自适应选择必须STOP后设置：0关闭、1实际采用、2影子；只有实际BALANCE且原电机许可成立才生效。起摆期间保持原算法。运行中修改会被拒绝。

“加载本包E工程候选（仅影子资格）”使用包内具体JSON，按关闭、清除、逐项写入/读回、影子资格提交的顺序工作；完成后仍为0关闭。若要观测，须停止时另选2影子。这份候选的Ku/Tu为软件单位换算构造量，不是机台实测，来源声明不具备实机资格，勾选按实机提交会拒绝，不能直接用于模式1。

已有实机合格配置可从“自适应配置 / 来源校验”导入；格式见 `machine_profile.template.json`。实际采用必须有经过筛选的配置及独立积分许可。页面显示选择/生效模式、配置标志、计算时间和完成采样的真实Kp/Ki/Kd。页6增益与页7积分各自带时间，不能跨页伪装成同一采样。

所有写入均先验证停止条件，每项写ACK后再独立READ确认。超时、拒绝、STOP或断线都会取消剩余项，不重发运动或恢复会话；已完成的部分保留真实结果。断开串口不等于停止电机。

## J280 接线

断电后接 U127：红VIN→H2-1(5V)，黑GND→H2-2，白SCL→H2-75(Y4)，黄SDA→H2-73(Y5)，INT不接。先找H2的1脚标记，不按图片朝向猜针号。模块供电5V，I²C信号仍为3.3V开漏；不得把5V接FPGA信号。详细依据见包内 `J280_WIRING_CN.md`，不能套用ACG525针脚。

本轮不接硬件：安装方向、实际定位到达、机械停止、起摆成功率及加负重效果仍需实物验收。轨迹完成代表命令执行完，不代表实物已稳定到位。
