# J280 V1 三种起摆接入平衡修复版

本包已完成新的完整综合、布局布线和原 50 MHz 时序验收，可以用于 J280 / GW2A-LV55PG484C8/I7 下载。交付日期：2026-10-27。本次没有连接或烧录硬件，尚未验证机械平滑性。

## 本次修改

保留单次激励、惯性辅助、峰值触发多组脉冲三种起摆，以及原固定 PID 平衡和手势功能。只修改起摆进入平衡时的共同接入逻辑：起摆源完成后，等待进入原有父级接入窗口，再以当时旋臂位置建立 HOLD 锚点；沿用已有复位/prime 顺序，取得新的完整角度计算帧后允许进入平衡。资格丢失会重新捕获。原有 250 ms 超时、STOP/急停、故障保护均保留。

这项修复避免了先在较早位置清历史、随后使用过时角度帧进入平衡造成的拉回。它不将位置目标重新设到最初 ZERO。实际接入后发生两计数位移时，位置 P 仍正常恢复该小位移；离线该例为 P=-5、D=0，不会屏蔽正常位置控制。

32 项实际构建输入中仅 `src/forest_d1_system.v` 改动，其余 31 项与已验收原版逐字节相同。没有重写起摆算法、PID、ADC、编码器、PWM 或通信。原默认角度 P/I/D=49/0/251，位置 P/I/D=25/0/610，周期为 5 ms/25 ms；各独立起摆参数库及可调范围保留。

## 使用

1. 整体解压到短目录，例如 `D:/J280_V1`。不要只复制启动器或把 `.fs` 文件当成上位机。
2. 位流为 `V1/bitstream/J280_V1.fs`；目标器件必须为 J280 的 GW2A-LV55PG484C8/I7。下载操作使用你现场的已确认流程，本包不会自动下载。
3. 双击 `Start_V1.cmd` 打开原配 V1 窗口。固件身份 `0x46443231`，wire=2，schema=`0x46443203`，UART 2 Mbaud；不要混用旧 FD1W 或其他版本窗口。
4. 按 [J280 接线说明](docs/WIRING_CN.md) 保留现有电机、编码器和 ADC 连接。M5 U127 仍为红线 H2-1/5 V、黑线 H2-2/GND、白线 SCL/H2-75、黄线 SDA/H2-73；INT 不接。该接法不适用于 ACG525。
5. 原套件使用默认配置 0：1080 物理计数/圈；IP570 使用配置 1：1040 物理计数/圈。套件差异见 [编码器说明](docs/ENCODER_KITS.md)。先 STOP 并确认 PWM=0，再选套件、明确校零，然后按现场已验证方法运行。两套实物的电平、方向和机械起摆表现仍需现场确认。
6. 三个起摆页分别保留各自参数和独立读回；不要求重新填写一套新参数。完整按钮说明可查 [原配操作说明](docs/README_CN.md)，其中五版本历史验收描述不代表本次新增验证。
