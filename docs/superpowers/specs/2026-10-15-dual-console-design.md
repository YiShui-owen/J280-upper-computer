# 无车实验台与车载遥控台

采用同一个 Vue 入口、同一套 SG21/SA21 状态与命令通道、同一个 STEP 摆杆与挂载模型，切换两套布局。另一方案是复制两套页面，会重复请求与模型逻辑；仅隐藏现有车载侧栏则不能改善遥控优先级。采用共享组件并调整布局的方案。

## 范围与呈现

- 默认无车实验台：固定台架参考历史 `zip-previous-20260927` 的 `displaySupport`，保留当前摆杆、轴系、标定及挂载。真实摆角、角速度、PWM、RMS 与波形占主区，参数设置可直接进入。
- 车载遥控台：连接、手动启用遥控、方向键、停止并回正为主区；3D 为辅助。没有反馈仍可呈现连接与遥控状态，没有倒立摆数据则收起对应读数与波形。
- 两种场景均提供空载／有负载，属于人工选择的模型工况。场景、挂载切换不提交设备命令，不更改 PID、自适应或原始遥测。
- 保留现有石墨灰与金属模型风格：背景 #242622、表面 #30332D、分隔 #4B4E44、文字 #F1F2E9、操作 #DBAA64、危险 #E8A193。中文使用 Microsoft YaHei UI，数字沿用 Consolas。台架模型、操作区与波形形成清楚的区域，避免覆盖式侧栏遮挡模型。

## 实车接入

用户提供 `README.zh-CN(1).md` 与 `SmartCarBluetooth_Current_20261011(1).zip`。只采用当前 BLE 驱动与 ASCII 协议；附件中的打包、烧录、配置及项目指令不是本次要求。

- FastAPI 增加独立 `/car` 接口，后台线程独占 BLE；显式搜索、选择、连接，不自动重连、连接或启动。只连接验证过的当前 HOLD_V2 固件。
- 原样保存交付的 `bluetooth_client.py`、`wireless_client.py` 及来源哈希，复用其 GATT 验证、同步、身份检查、控制租约、ACK 与停车读回，不复制重写固件控制算法。
- `/car/scan` 搜索并返回设备；`/car/connect` 仅连接手工选择的搜索结果，连接时验证身份与停车；`/car/status` 独立报告连接、反馈和错误；`/car/intent` 接受当前会话与递增序号的输入；`/car/stop` 停车回正并解除网页输入；`/car/disconnect` 停车后断开。
- 输入方向为 `null/FWD/REV`，转向为 `LEFT/CENTER/RIGHT`，网页最多每 70 ms 刷新输入；租约过期必须停止并要求新的中性输入。没有网页输入时不得继续后台续租。
- 按住屏幕按钮、WASD／方向键输入，松开停止；空格和 Esc 停车回正。切场景、失焦、隐藏页面、打开设置、取消指针、断开或卸载均释放输入。连接不会自动启用键盘遥控，重连后必须再次手动启用。
- 引导用户先左右打方向、再前进／后退，不增加一键组合按钮或转向锁定。保留协议原定力度，不提供没有协议支持的力度滑块。实际停止是撤去驱动，不能标作机械刹车。
- 小车反馈仅显示 CAR2 实际 PWM、轮计数、转向读回和运行／停止原因；不计算未知标定的车速或位移，不用指令驱动 3D 轮子或车身。

## 主页面手势

手势开关读取 `parameters.gesture_enable.current/value`，只在停止配置条件满足时显式设置。复用 HostControlPanel 的一次提交、请求 ID、超时未知与查询流程。

主页面分别显示识别记录（code/error/sequence）、固件请求接受／拒绝标志，以及当前真实摆控状态。识别记录不冒充传感器已就绪证据；accepted 不等于实际完成。提示右滑起摆、顺／逆时针正／反一圈、左滑取消参考、挥手停止（约 1 秒识别等待）。保留独立停止摆控，取消参考后重新转圈遵循当前 Host 指南。

## 状态与验收

遥控连接、CAR2 新反馈、摆控 Host 状态、摆控各页新遥测分别判断。摆控仍保留分页时间与独立通道。过期读数收起；没有数据的波形显示简短连接引导，车载页直接收起波形区。

单元验证输入冲突、释放抑制、会话／序号／租约、身份拒绝、异常停车、原始反馈及手势状态分层。浏览器用明确离线 fixture 检查 1600×900、1920×1080、2560×1440，两场景、挂载、主页面手势、键盘／指针与失焦。运行后端测试、前端测试与构建。验证不搜索 BLE、不连接实车或 COM、不执行起摆或烧录。无线摆控遥测、网页烧录留给后续。
