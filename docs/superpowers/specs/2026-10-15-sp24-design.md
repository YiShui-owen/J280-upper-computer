# SP24 上位机适配

用户已要求修改当前上位机。保留双场景、空载／有负载、模型、SG21／SA21 和小车 BLE。只做软件适配和明确离线验证，不烧录、枚举或连接硬件，不发送实物动作或恢复参数。

## 架构

继续由唯一配套 Host 持有 COM。SP24 原始 Host 保存到 `host/sp24/gesture/host`，预设保存到 `host/sp24/presets`，保留原包目录关系和 SHA256 来源记录。外层 `host/sp24_bridge.py` 为原 Host 增加只读 `/waveform` 游标批量接口；原 `/status`、`/command`、请求 ID、STOP 与 UART/CRC/控制算法保持原样。新入口 `launch_host.py precise` 先安装这个外层接口，再调用原 Host main。启动菜单增加第三项 SP24。

选择方案：采用内存历史批量读取；不采用轮询最新帧（会漏掉中间样本），也不尾读 CSV（引入刷盘延迟并绕过内存有效性信息）。外层只读接口继续使用原 loopback、X-J280-Local、Origin/Host 检查。

## 固定接口约定

SP24 身份 `53503234 / 53505424`。后端支持 `auto/SG21/SA21/SP24`，保留用户当前配置，不在更新时自动切换连接。SP24 参数增加 `move_degrees:1..360`、`left_negative:0..1`；自适应功能支持 SA21 和 SP24；不直接开放任意 profile 提交参数。`apply-preset` 仅 SP24，完整 value JSON 与原 Host 约定一致，原 Host 负责实际停止、只读前提、ACK 和逐项读回。

只读 `/waveform?after=<cursor>&stream=<token>&limit=<1..512>` 返回 `stream,cursor,overrun,samples`，建议还返回 head/tail。游标使用当前历史的累计 accepted 编号，stream 随 wave 对象改变；过期／其他 stream 游标明确 overrun，不把缺失隐藏。响应持锁复制有限条，不修改 wave、记录或控制。原始宽整数向 HTTP/JS 发送前转十进制字符串，保留所有原始位；每条加由 Host 时钟换算的 epoch 秒 `received_at`。JSON 只允许有限数值。

后端状态保持既有字段，另加：

- `precision`：原 `precise_telemetry` 统计、日志错误/积压/丢行、桥 overrun、`origin_count` 十进制字符串。stale 采用原 250ms；PID样本龄和接收龄分别显示。
- `gesture_event`、`gesture_runtime`：原 page8/9 信息加各自 `received_at`，按各自计数/板时去重，不将重复查询当新事件；重连首份保留事件不宣称新识别。
- `arm_relative_deg`、`target_relative_deg`：以当前精确流/设备 epoch 首份编码器为局部原点计算（Python 先精确整数相减再转换），不冒充机械绝对零点。

精确样本传到网页的约定：

```
sample_id: string, received_at: epoch seconds,
plot_at: capture 所在板端轴映射到 epoch seconds,
measurement_at: 同一轴上的 sample_ms epoch seconds,
sequence: u32, session_epoch: integer, sample_ms: u32, capture_ms: u32,
gap_before: bool,
angle_deg, angle_velocity_deg_s, alpha_ref_deg,
arm_relative_deg, target_relative_deg, duty_actual_percent: finite number | null,
raw: {encoder_count:decimal string,target_count_q32:decimal string,
      reference_rad_q20:decimal string,...},
channels: [上述绘图字段]
```

`plot_at` 按板端 capture 的展开时间推进，不按网络批次到达时刻堆点。测量通道用 measurement_at，PWM 用 plot_at。重复 measurement epoch 不生成新测量（对应字段 null）；真实停机测量仍按原 Host 的 host_measurement_fresh 判定显示。目标/参考还要求 PIDvalid；PWM/保护属于 capture 时刻，不能标为相同 PID 计算瞬间。缺帧断线、重启分 epoch，不跨缺口补线或插值。后台与前端至少缓存30秒*100Hz，去重保留全部有效样本。

## 页面

沿用当前仪表配色与布局。SP24 波形改为三组：摆角与角度参考、旋臂局部角与目标、实际 PWM，公共板端时间轴；旧固件保持原三通道。绘图按像素首/最小/最大/末抽点保峰，保留原始样本不随绘图减少。小振幅不固定撑到 ±2°，有丢帧线与原始时间信息。

主手势区按版本给提示。SP24 为上滑起摆、左右相对定位/反向取消、圈2秒；起摆到接管完成期间包括挥手均忽略，独立 STOP 保留。分别显示识别事件、动作/接受原因、当前 runtime，不能把轨迹完成当实物稳定。SP24 主界面提供传感器就绪/屏蔽与接管信息，详情仍在设置。参数页增加相对转角/方向映射、显式六项预设及 E工程候选仅影子导入；所有草稿、选取、加载均不自动写设备。

SP24 显示标定单独保存，不继承 SG21 实测偏移；3D仍不把局部编码器角解释为硬件旋臂绝对角。小车、摆控 STOP 独立。
