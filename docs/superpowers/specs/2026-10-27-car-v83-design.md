# 小车 V8.3 网页接入设计

用户已明确要求开始接入。依据 AGENTS.md，在现有项目完成修改，不另开强制设计审批、分支或提交；不连接、扫描或烧录实车。

## 范围与选择

采用原样 V8.3 Python 控制器、协议与传输模块加网页外层适配。另一方案是重新实现 RC83 协议，增加重复维护和控制偏差；仅在网页唤起原 EXE 则无法提供统一控制界面，因此不采用。

日常网页使用 RC83，旧 HOLD_V2 驱动保留历史追溯和已有回归测试，不注册成第二个网页版本。摆控链路和已确认的模型、主布局不变。网页保留显式扫描/选择/连接/启用，不自动重连。上游源码、默认限幅和控制保护不改。

## 后端与接口约定

新建 `backend/car_v83_service.py`，向 `car_api.py` 提供 CarService。服务在一个独占线程创建 BLE Transport、Session 与 Engine；HTTP 输入仅写最新意图，不操作 BLE，也不等待运动 ACK。共享 CarError 类型沿用 car_service.py，旧服务只供历史测试。

原样运行模块置于 `car/v83/`，包含 speed_protocol.py、speed_control.py、speed_transport.py，来源、文件哈希及配套固件单独归档，不复制 cp314 原生依赖到现有 Python 环境。原始配置读取使用上游 load_steering_limits，坏配置回退确认默认并报告。

保留 `/car/status /scan /connect /intent /stop /disconnect`，增加 `/profile /boost /brake`：

- `/intent`：session、递增安全整数 sequence、direction（FWD/REV/null）、steering（LEFT/CENTER/RIGHT）、speed_q8（128..4096，默认1024）、route（0..8，默认0）、slow_percent（25/50/75，默认50）、steer_percent（10..100）。route 与手动 direction/steering 互斥；不传零速启动。
- `/profile`：session、profile（0/1），只在停车且输入为中性时更新；等待新档位读回。
- `/boost`：session、sequence、peak_q8（1024..6144）。一次性请求，不自动重试；仅在新鲜手动前进、快速档、回正且峰值大于当前速度时调用原 Engine.boost。
- `/brake`：session，优先撤销输入并调用原 Engine.cancel(brake=True)，待新静止反馈，再轮换网页会话。
- `/stop /disconnect`：保留会话轮换/验证语义。先撤销输入，使在途 ARM 无法继续启动，再由所有者线程处理。
- status 包含 connected、identified、session、feedback_fresh、telemetry、received_at、phase、error、neutral_required，以及 protocol=RC83、profile（仅从反馈）、motion（manual/route/null）、preparing、route_id、steering_limits。telemetry 原样 CAR8 字段；不生成假读数。

网页输入租约200ms，只由 HTTP 输入接收时更新。租约断档必须先停车，随后中性输入才能重新操作；不能由后来的中性和运动输入隐藏断档。STOP/失焦/断链/故障轮换或撤销授权，旧token/序号和排队boost不恢复动作。路线完成后按住不重复启动；必须释放再按。状态新鲜度按真实接收时间判断，旧帧/aux不得续新鲜度。故障保留在线GATT时先停车确认或重新握手；真实断链不自动重连。

## 前端

保留石墨灰、银色模型及琥珀色操作，原方向盘及 STOP 保留。小车操作区增加紧凑速度滑块（计数/5ms）、普通/快速档、手动急加速峰值与Shift按钮、独立急刹/空格、转向幅度、轨迹下拉及按住按钮/F8、慢段比例。速度/慢段比例在运行时只更新最新意图；切轨迹撤销动作。

Esc为普通STOP；Shift只触发一次，自动重复无效；F8按住轨迹可同时用鼠标调速。鼠标与F8为独立输入源；松开一个来源不取消另一个。失焦、隐藏、设置、切场景、回放禁控取消所有输入；物理仍按住的键必须释放再按。连接/异步返回不能在页面取消后恢复遥控。

新增控件可放在折叠区，但急加速和急刹应直接可见。保持1600×900、1920×1080、2560×1440下可用，不挤压模型和摆控显示。显示当前目标/渐变目标、左右5ms编码器、PWM、舵机比较值、路线阶段；没有新反馈则收起实时读数。首次上线告知需要RC83配套固件，绝不自动烧录。

## 验证

先写失败测试，再实现。后端使用实际原样 Session/Engine 加明确模拟/合成传输，仅测试中可用SimTransport；运行入口只创建BleTransport。覆盖版本拒绝、一次性boost、BRAKE与STOP区别、T/U/K及完成抑制、输入租约、旧token/序号、ARM中取消、状态陈旧与故障恢复。前端使用Node纯输入/控制状态测试、Vue编译及浏览器离线fixture，检查快捷键、并发取消、回放和三个桌面分辨率。运行全部后端/Node测试及Vite构建。实车方向、无线时延和制动距离保留人工验收。
