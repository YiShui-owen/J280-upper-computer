# SP24 上位机适配 Implementation Plan

> 使用 subagent-driven-development 执行可独立的通信与绘图任务，主线程负责参数/手势页面及集成。工作区已有大量用户修改，不创建提交，不覆盖现有配置。

**Goal:** 当前上位机完整接入 SP24 的批量精确遥测和新版手势／参数，同时保留 SG21、SA21、小车和两套布局。

**Architecture:** 原样 SP24 Host + 外层只读游标接口 → FastAPI批量适配 → WS → Vue/ECharts。具体字段与时间单位以同名 spec 为准。

**Tech Stack:** Python、原交付 Host、FastAPI、Vue、ECharts、Three.js，不升级依赖。

## Global Constraints

- 不访问真实 COM/BLE/JTAG，不烧录、不发送动作/写参数，不自动连接或恢复。
- 不改交付控制源码、参数默认值、UART/CRC、STOP、ACK/独立读回；保留来源哈希。
- HTTP接收/ACK不等于实际动作完成；操作只显式发一次，超时不重放。
- 宽整数以十进制字符串到JS，设备时间、Host接收时间与PID/capture时刻分开；不生成假数据。
- 保存至少30秒100Hz样本，缺帧和epoch分段，原始缓存不跟随绘图抽点丢弃。
