# 小车 V8.3 Implementation Plan

> 使用 subagent-driven-development 与 dispatching-parallel-agents，在独立文件范围并行实施，按统一接口集成及复核；不提交或推送。

**Goal:** 现有网页上位机完整接入小车RC83速度、急加速、急刹及八条轨迹。

**Architecture:** 原样交付speed_*模块 + 单所有者线程服务 + 独立/car接口 + 原Vue操作区扩展。

**Tech Stack:** Python/FastAPI、Vue/Vite、Node test、原Bleak依赖。

## Global Constraints

- 不扫描、连接、运动或烧录实车；无自动连接/重连。
- 原样V8.3模块的控制算法、保护及限幅保持字节一致。
- HTTP最新意图200ms租约；STOP优先取消、会话隔离、一次性boost无重放。
- 不改倒立摆链路、模型及已确认主布局；不生成假车速或假在线。
- 工作区已有改动保留，不提交、不推送、不擅自切分支。
