# 比赛答辩测控界面实施计划

**目标：** 1920×1080 一屏内，以 64% 的机械舞台和 36% 的测控区展示真实遥测，兼容 1600×900、2560×1440。

**结构：** `App.vue` 保留现有通信和命令函数，负责布局、遥测缓存及工程入口；`DigitalTwin3D.vue` 保持模型与映射边界；`WaveformPanel.vue` 独立管理唯一 ECharts 实例；`waveform.js` 生成三通道共同时间窗口的数据和配置。

**约束：** 不修改 backend、端口、遥测协议、mailbox、START/STOP/PID 下发流程。保留先前去雾修改。正式页面去除装饰英文、重复架构信息、扰动恢复卡和调试入口。颜色以深蓝、青蓝、浅蓝、琥珀及状态色为限。
