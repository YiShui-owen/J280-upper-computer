# 波形空间与模型比例调整实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 收紧中部 3D 区域，模型在屏幕上稍放大，将腾出的高度交给波形，摆角默认最小量程改为 ±60°。

**Architecture:** 沿用现有三列布局、跨列透明模型和三组横排波形，通过 CSS 调整垂直空间分配，通过相机显示倍率补偿 stage 缩短。保持各层默认量程一致，不改变原始样本、缓存、数据刷新及姿态换算。

**Tech Stack:** Vue、Three.js、ECharts、Vite、Node 内置测试、离线 Playwright fixture。
