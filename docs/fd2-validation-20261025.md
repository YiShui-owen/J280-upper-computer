# FD2 V1～V5 适配验证记录

日期：2026-10-25。范围：本机软件适配与明确标注的离线测试。开发验证期间未连接 COM / BLE / JTAG，未烧录或执行电机动作；验证结束后，按用户要求将本版提交并同步到 GitHub，恢复标签见 `VERSIONING.md`。

## 实现结果

- 日常启动器与网页版本选项切换为最新 V1～V5。V5 不提供自动起摆；V3 展示角 P/D 自适应，V4/V5 展示旋臂运动原点、参考、最终目标及独立到位状态。
- V5 交付包中的共用 Host 和 CPython 3.12 原字节导入；2250 项文件均与来源清单 SHA256 及大小一致。通用忽略规则对原运行时的必要扩展、标准库及公共证书作精确例外，避免后续打包遗漏。
- 原生 T 控制帧按游标批量采集，独立 D 诊断保留板时，宽计数保留字符串；120秒缓存与保峰绘图、JSON窗口导出、原生日志 RX-only 回放。
- HTTP 请求只转发一次。会话切换后旧请求不补发；ACK同时匹配 wire ID 与 opcode；已知拒绝和通信结果未知分别处理。STOP / ESTOP 不被待完成的普通网页请求阻塞。
- 原控制源码、参数、协议及保护未修改。历史适配与小车驱动保留。

## 实机到手后的验收顺序

1. 按已烧录版本启动原 Host，核对 firmware / schema / wire，确认USB状态与实际200Hz接收、CRC、缺序及完整日志落盘。
2. 电机停止时对照原 Host 校验摆角、旋臂方向、累计计数和模型姿态；需要时只调整网页显示标定。核对故障及STOP、断流时的实际行为。
3. 分别验收 V1三套起摆，V2手势，V3手动平衡与角P/D实际采用。不能把识别事件或ACK当作动作成功。
4. V4逐个检查六位置的方向、动作原点、最终目标及到位；V5在手动平衡条件下逐个检查六轨迹的参考完成和实际收敛，保留完整日志。
5. 单独核对BT10命令/ACK与USB遥测；小车WH-BLE102另做方向、松开停车、失焦及无线断流检查，最后再做车载组合演示。

当前结论仅为软件与离线数据链路通过检查；真实起摆成功率、定位误差、负载效果、无线时延和停车距离尚未验收。
