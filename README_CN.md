# J280 车载旋转倒立摆比赛展示

这是一版面向 FPGA 创新设计大赛现场展示的上位机，不替代原 V5.12 tuner，而是叠加在已经验证稳定的 tuner 之上。

## 为什么这样接

原 tuner 已经负责：
- COM 串口独占
- V5.12 遥测接收
- HOME-M29 自动起摆
- 安全停止
- mailbox 远程命令

展示上位机因此不直接抢 COM 口，而是：

`FPGA -> UART -> V5.12 tuner -> log/mailbox -> FastAPI -> WebSocket -> Vue/ECharts`

这样既保留稳定的工程链路，又能把比赛现场 UI 做得更漂亮。

## 第一次使用

1. 需要真实摆控数据时，按原流程运行 `START_HERE.bat`，完成烧录、抓零，并让 V5.12 tuner 保持运行；只查看界面可跳过此步。
2. 双击 `INSTALL_ONCE.bat`，只需要运行一次。
3. 检查 `backend/config.json` 中的路径：

```json
"tuner_project_dir": "D:\\FPGA\\实验\\J280_V512_1MS10MS_PID_HANDOFF_20260924\\project"
```

如果你的交接包位置不同，只改这一项。
4. 双击 `START_SHOWCASE.bat`。
5. 浏览器自动打开 `http://localhost:5173`。

## 比赛展示界面

建议在 1920×1080 分辨率下按 F11 全屏，也支持 1600×900 和 2560×1440。

- 石墨灰、金属银和琥珀色的一屏展示；中央为四轮底盘、旋臂、摆杆组成的完整模型，保留旋转、缩放、平移和重置视角。
- 左侧显示真实摆杆偏角、旋臂角度及近 3 秒 RMS；右侧预留底盘驱动占空比、编码器和方向请求，小车未接入时显示空读数。
- 「底盘」标题下显示“未连接”；“启用遥控 / 停止小车”暂未启用。当前阶段重点为比赛展示 UI，等拿到实车后继续功能接入。
- 三通道波形默认共用最近 10 秒窗口；鼠标停在波形区时扩展为最近 30 秒并继续实时滚动，移开恢复 10 秒。底部秒数表示距当前的时间，悬停提示显示本机时刻及毫秒。
- 前端缓存最近 30 秒收到的遥测；尚未实现历史回放。无数据时不生成演示曲线。
- 小车前进、后退、左右打方向和停止回正按钮直接显示在主画面右侧「底盘」区域；搜索与连接放在「设置」中。小车控件当前为禁用状态，等待实物接入。原有自动启动、实机摆控停止、PID 和姿态标定继续保留。已有摆控遥测时，顶部另显示“停止摆控”。原有 ±12 q2 扰动按钮仍在「调试工具」折叠项中，写入命令成功后在波形中标记事件；这不等于确认实机已执行。
- 主画面只保留指标、操作和当前状态。没有摆控数据时显示“无数据”，断流后显示“数据中断”；波形注明 10 秒或 30 秒窗口。RMS 仍使用最近 3 秒摆角，转向项仍是指令值。

场景组件 `frontend/src/DigitalTwin3D.vue` 与页面布局独立；轮子与底盘的显示不改写原有摆控标定和原始遥测。波形组件为 `WaveformPanel.vue`，`waveform.js` 支持堆叠和横向布局，共用真实时间窗口。后端接口、端口、配置和命令流程保持原样。

摆杆使用用户提供的 `L型摆臂(1).STEP`，保留安装孔及端部折边，转换为本地 GLB 后加载。以轴端直径 7 mm 孔的中心作为显示转轴，等比适配原场景的摆杆高度；底盘和旋臂仍为示意模型，并非完整装配的实物尺寸模型。原 θ/α 映射、两点显示标定和插值保持原样。原件与转换方法见 `frontend/model-sources/README.md`；实物安装方向仍待联调确认。

## 没有实车时

按上述步骤启动页面，可查看完整车载倒立摆模型及连接、遥控面板布局。小车读数保持空态；摆控日志未接入时显示空读数和等待波形。当前页面没有小车模拟动作，不生成演示曲线。

`CarControlPanel.vue` 负责小车连接布局，`CarControlPad.vue` 负责主画面方向按钮。旧版 `carSimulation.js`、`useCarPresentation.js` 源码保留，但当前页面不调用。场景中的底盘保持固定展示位置；车速、里程、实际舵角和带摆负载运动均待实物标定与联调。当前版本尚未开放实车控制。

前端验证（在 `frontend` 目录）：

```sh
node --test tests/waveform.test.js tests/carSimulation.test.js tests/pendulumModel.test.js
npm run build
```

## 安全

网页里的 START 会写入原 tuner mailbox，由原 tuner 执行 HOME-M29，而不是绕过原安全流程。
现场演示仍必须保持旋臂运动范围内无人、无线材和杂物。
