# J280 旋转倒立摆上位机

当前日常版本为 **FD2 V1～V5**：V1/V2/V5 已接入 2026-10-27 最新交付，V3/V4 沿用 2026-10-25 交付。共用「无车实验台 / 车载遥控台」、原 STEP 模型和石墨灰 / 琥珀色界面。旧 SG21、SA21、SP24 的依赖及适配保留用于追溯；旧操作说明归档在 [历史 README](docs/history/README_CN_20261016.md)，其中旧启动和协议步骤不适用于新版本。

2026-10-27 更新：V1/V2 修复起摆进入平衡时过早锚定旋臂位置、使用旧角度帧造成的拉回；V5 为现有源码重新编译，继续保留六位置和六轨迹。三版配套 Host/runtime 的 2250 个文件与现有原样依赖完全一致，展示界面及启动方式继续沿用。当前五版位流随仓库保存在 [firmware](firmware/README.md)，与本机工作区 `现场烧录固件/` 一致；旧版和完整原包的本机备份位置见 [更新与校验记录](docs/fd2-update-20261027.md)。文件更新未执行硬件下载，实际板上是否已刷新版不能由未变化的固件身份判断。

## 五个版本

|版本|页面展示与操作|起摆方式|
|---|---|---|
|V1|SWM4 / SA21 / 144 三套起摆、光学手势、真实波形|按 Host 当前起摆方案|
|V2|SWM4 起摆、光学手势与旋转状态|SWM4|
|V3|角 P/D 自适应，基值 / 实际值 / 候选值，1秒及5秒实际均值、覆盖率与趋势|手动扶直、显式抓零和平衡|
|V4|三套起摆、六个相对位置，动作原点 / 参考 / 最终目标 / 到位状态|按 Host 当前起摆方案|
|V5|六个相对位置、六种有限轨迹、规划完成与实际跟踪到位|手动扶直、显式抓零和平衡；无自动起摆|

V4/V5 的位置和轨迹指**旋臂**运动，不是小车定位。主要参数继续在原 Host 设置；网页提供展示和必要显式操作，不自动改参数。所有动作遵守原 Host / 固件条件，ACK 表示接受请求，不表示运动完成。

无车实验台右侧可直接选择 V4/V5 的 60°～360°相对定位；V5 可切换到六种有限轨迹，无需打开设置窗口。右侧分别显示设备动作、请求结果、参考完成和实际到位，并提供「取消并保持」和抓零。V1/V2 的新手势以大图标和短时琥珀色强调显示；首次连接或断流恢复时保留的旧事件不触发强调，诊断信息按需展开。

## 启动

1. 已安装依赖的当前工作区可直接启动。首次配置使用 `INSTALL_ONCE.bat`；若已有 `.venv`，后端依赖应安装到 `START_SHOWCASE.bat` 实际使用的 `.venv`：

   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
   ```

2. 关闭此前的 Host、网页后台和前端。双击 `START_HOST.bat`，选择**已烧录**的 V1～V5；在原 Host 中明确选择串口并连接。启动器使用随交付的 CPython 3.12，保留原 BT10 扩展依赖。启动程序不会自动连接、烧录、抓零或运行。
3. 双击 `START_SHOWCASE.bat`，打开 `http://localhost:5173`。在「参数与连接」中选择自动识别或预期 V1～V5，默认桥端口为 8371。
4. 版本身份、新鲜状态和原 Host 条件满足后，才可显式操作。8371 同时只运行一个 Host。网页 STOP 与小车 STOP 分别作用于对应设备。

链路为 `FPGA → USB/UART → 原 Host → 本机 HTTP → FastAPI → WebSocket → Vue`，网页不直接占用 COM。网页后端使用 `127.0.0.1:8000`，Vite 使用 `localhost:5173`。只查看界面或使用独立小车遥控时，可以不启动摆控 Host；无有效遥测时显示空态。

## 暂时没有实物

可以继续验证界面、协议解析、历史波形和操作守卫。原日志回放不会伪装在线，也不会把历史 TX 再发给硬件。

在项目根目录打开 PowerShell，运行空态预览：

```powershell
.\host\fd2\upstream\runtime\python.exe -B -X utf8 launch_host.py V5 --offline-preview
```

或回放原 Host 导出的 **ForestFive.Physical.v1 会话 ZIP**，将路径和版本替换成实际日志：

```powershell
.\host\fd2\upstream\runtime\python.exe -B -X utf8 launch_host.py V5 --replay 'D:\logs\ForestFive_V5_session.zip'
```

然后启动 `START_SHOWCASE.bat`。交付的工程 ZIP 不是会话日志，不能直接拿来回放。回放读取 `session.json` 与 `physical_chunks.bin`，校验版本及原始 chunk CRC，只解释 RX。页面明确显示「离线回放」，摆控及小车硬件操作均禁用；结束后保留最后波形。附加 `--replay-speed 2` 可按两倍速度播放，曲线仍按板端时间排列。

目前没有实物验收结论。代码及离线日志能验证数据路径，实际 USB 吞吐、蓝牙、姿态方向、起摆、定位精度和停车仍需实机检查。

## 波形与数据含义

- 三组波形：摆角 / 角度参考，累计旋臂角 / 当前运动参考 / 独立诊断最终目标，实际 PWM。
- T 控制事务标称 200Hz，逐批按游标读取中间帧；D 诊断保留自己的板端时刻，不伪装成同一时刻测量。图表刷新频率不等于硬件采样率。
- 默认查看10秒；鼠标悬停波形区查看120秒。前后端保留完整窗口样本，绘图按像素保留首尾与极值，缺帧、重启、换会话断线，不补造数据。
- 摆角最小量程默认为 ±30°（10°/格），可选择 ±60°；超范围时扩大并保持，点击「重置量程」按当前窗口重新确定范围。旋臂使用累计角并保留至少 720°显示跨度，包含实测、参考和独立最终目标；PWM 固定 ±100%。实时与历史窗口分别保存量程，显示量程不改变原始样本及导出。
- 「导出当前缓存」保存窗口内样本和原始计数字符串。完整会话仍以原 Host 日志为准，120秒窗口不替代完整记录。
- 状态、控制、诊断各自判断500ms新鲜度。停止更新后收起相应即时读数和运动条件，不靠重复轮询刷新数据年龄。
- 摆角使用 `(ADC12 - 3085) × 345 / 4096`，旋臂累计角使用 `count × 360 / 1040`，实际 PWM 使用 `Q15 × 100 / 32768`。宽整数原样保存为十进制字符串，浮点只供绘图。累计角不是机械绝对零点。
- 手势序号及识别与全局最近动作原因分开显示；不能把最近动作原因自动归因于某次手势。V3 使用原 Host 的时间加权实际增益均值，不自行合成“自适应效果”。

3D 旋臂按有效累计角的周期内姿态显示；FD2 摆杆使用同一完整 T 帧的 `quiet_q4` 与 `zero_q4` 推导未裁切姿态，按原 `6921 Q20 弧度/ADC码` 比例换算，要求该帧零点有效。控制显示角正向可能裁到 85.071°，因此左侧读数和波形的控制角不能作为全摆程姿态；3D 的独立换算不改动这些原始控制读数。姿态无效时保留上一姿态并提示，不依据 STOP 或故障状态猜成下垂。

空载 / 有负载只切换挂载模型，姿态标定只改显示，不改变原数据、PID 或硬件零点。V1～V5 标定采用独立 v3 存储，首次身份到达及版本切换均正确加载，隔离旧控制显示角域标定；SG21/SA21/SP24 继续使用原 v2 标定。停止状态或 FAULT 且实际 PWM=0 时，可在实物下垂静止后使用「下垂对齐」。V5 STOP 后自然下垂仍可能触发板端角度越界保护（1），该现象不会由显示对齐清除。STEP 原件及转换说明见 [模型来源](frontend/model-sources/README.md)。

## 蓝牙与小车

FD2 V4/V5 的 **BT10** 用于摆控命令和 ACK；高频摆控遥测仍经 USB。原 Host 的键盘控制由电脑转发，不代表蓝牙键盘直接连接到 J280。

小车仍使用独立的 **WH-BLE102 / HOLD_V2** 驱动，见 [小车来源与接口](car/README.md)。在车载页显式搜索、选择、连接，再启用遥控；WASD / 方向键或屏幕按住输入，松开停止，空格 / Esc 停止并回正。失焦、隐藏页面、打开设置、切场景会取消遥控。没有新 CAR2 反馈时不显示车速、位移或模拟运动；车辆遥控与倒立摆连接分别判断。
