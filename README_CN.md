# J280 旋转倒立摆上位机

同一上位机提供「无车实验台」与「车载遥控台」，支持 2026-10-15 交付的 SP24 精确遥测版，并保留 SG21 手势版和 SA21 自适应版。各版共用 STEP 摆杆与挂载模型。配套 Host 原样保存在 `host/`；小车通过独立 BLE 链路连接，原样依赖与来源见 `car/README.md`。

## SP24 使用与兼容

SP24 固件身份为 `53503234 / 53505424`，必须使用匹配的 SP24 Host。更新软件后关闭旧的网页后台/前端，再运行 `START_SHOWCASE.bat`；刷新网页不会重新加载 Python。在 `START_HOST.bat` 选择 **3 SP24**，在该 Host 中显式连接；网页「参数与连接」选择 **SP24** 或 **自动识别** 并应用。已有连接配置不会被更新程序覆盖；8371 同时只能运行一个匹配 Host。位流仍由用户单独按原交付流程烧录，本软件不自动烧录或替换当前固件。

SP24 原始运行依赖位于 `host/sp24/gesture/host`，配套预设保持包内目录关系；来源及哈希见 `host/sp24/SOURCE.md`。`launch_host.py precise` 在原 Host 外安装只读批量遥测桥，再调用原入口。`/waveform` 按游标从内存历史读取中间样本，继续使用 loopback 与专用请求头检查；不改变原 `/command`、唯一串口所有者、STOP、控制算法或 ACK/独立读回。SG21／SA21 沿用原分页链路，小车 BLE 独立运行。

新波形标称100Hz、80字节一帧，展示摆角／角度参考、旋臂局部角／位置目标、实际PWM。按板端时间排列批量样本，并分别保留测量时刻和PWM捕获时刻；不把网络批次到达时刻当采样间隔。旋臂使用本次流首份编码器为局部原点，不是机械绝对零点，3D旋臂仍为示意。64位编码器、96位Q32目标以十进制字符串保留到网页，浮点仅用于局部坐标绘图。100Hz遥测与绘图刷新率、ADC/编码器物理分辨率不同。

原始缓存保留至少最近30秒，按像素抽点只减少绘图量并保留峰值；缺帧断线并标记，重启不跨epoch补线。停机时仍可显示原Host判定新鲜的真实测量；重复测量不延伸成新测量，目标/参考还要求PID有效。精确流超过250ms未更新后收起即时读数，显示接收龄、PID样本龄、实际帧率、缺帧、CRC及记录错误。原Host的 `telemetry.csv` 等完整记录继续保留，绘图不删除原始日志。

SP24 手势为**上滑起摆**；平衡就绪后左/右滑启动相对定位，默认50°，可停止时显式设置1..360°及方向映射。反向手势取消参考并保持，该次不反向启动，后续新手势可再次定位/转圈。正反一圈轨迹均2秒。**起摆至实际接管完成前，包括挥手在内的所有手势均被忽略，此间用独立STOP或物理急停。** 页面分别显示保留事件/原因与当前传感器/接管状态；轮询次数不等于新事件，接受/轨迹结束不等于实物到位稳定。

设置中的六项SP24预设先本地预览，只有点击「应用所选预设并逐项读回」才提交。基线、位置阻尼、位置慢积分、角度D80、角度I780各自独立，起摆70/230+70/230/最多1次另行提交；不会自动组合、标零或RUN。E工程候选先本地载入，导入固定使用影子资格且仍关闭，另行停止时选模式2才观察；不能声明为实机合格配置或自动启用实际采用。所有草稿与选择均不代表真实读回。

SP24 的3D显示标定独立保存，默认名义-180°下垂，不继承SG21的机台实测偏移；实物静止自然下垂且停止时可点「下垂对齐」。软件适配及离线回归不代表USB吞吐、实际起摆、方向、停车、定位或负重效果通过实机验收。

## 为什么这样接

数据链路为 `FPGA → UART → 对应版本 Host → 本机 HTTP → FastAPI → WebSocket → Vue/ECharts`。网页不直接打开 COM，不再读取 V5.12 日志或写入旧 mailbox。旧 V5.12 tuner 不适用于这两版新位流。

## 第一次使用

1. 首次双击 `INSTALL_ONCE.bat` 安装依赖。只查看界面时可先跳过硬件步骤。
2. 按交付说明显式烧录 SG21 或 SA21 的对应位流。本工程不自动烧录。
3. 双击 `START_HOST.bat`，选择与位流对应的版本，在 Host 中确认固件、选择串口并连接。各版默认使用本机 8371 端口，同时只启动一个对应 Host。
4. 双击 `START_SHOWCASE.bat`，浏览器打开 `http://localhost:5173`。在「参数与连接」中查看版本与真实状态。仅使用小车遥控时，可以不启动摆控 Host。端口或预期版本可在网页设置中修改；对应配置为：

```json
{"bridge_port": 8371, "firmware_variant": "auto"}
```

5. 先 STOP 并确认实际 PWM=0。冷启动 PID 为 0；在「PID 与滤波」中明确填写六个增益、积分使能、角度 D 滤波和窗口共九项，再提交并等待读回。也可在原 Host 中完成。零点标定和 RUN 均需单独点击，不会自动恢复历史参数。

SG21 身份为 `53473231 / 53475421`，SA21 为 `53413231 / 53415421`，SP24 为 `53503234 / 53505424`。自动识别仅接受这三组完整身份；指定版本不匹配时拒绝普通写操作。STOP 仍可发送给已识别的另一受支持版本。

## 比赛展示界面

建议在 1920×1080 分辨率下按 F11 全屏，也支持 1600×900 和 2560×1440。

- 顶部切换「无车实验台 / 车载遥控台」。默认无车；恢复历史固定台架支撑，左侧显示新鲜的摆角、角速度、实际 PWM 与 3 秒 RMS，右侧为主页面手势区。车载页扩大连接和方向控制区，3D 用作辅助展示。
- 两种场景均提供「空载 / 有负载」，默认空载；选择在场景之间保留。挂载沿用当前金属挂钩、夹紧端孔的固定盘和装沙容器，容器保持竖直示意。切场景与模型工况只影响显示，不代表检测到实际负载，也不切换 PID 或自适应。
- SG21／SA21 的 compact 页没有旋臂绝对角与硬件旋臂零点读回；SP24 采用局部原点显示旋臂数据，也不代表机械绝对零点。3D 旋臂姿态保持示意，不把编码器计数或假零值当作绝对角。没有摆角新数据时保留最后展示姿态并注明示意，不产生模型运动。
- 车载页分别显示遥控链路、车辆反馈、倒立摆连接；没有摆控遥测仍可使用小车遥控。没有对应新反馈时收起读数与波形，不生成车速、位移或假曲线。
- 波形默认共用最近 10 秒窗口；鼠标停在波形区时扩展为最近 30 秒并继续实时滚动，移开恢复 10 秒。SG21／SA21 使用原摆角、角速度、PWM三通道及本机到达时刻；SP24使用上述三组精确波形与板端时间轴。
- 前端缓存最近 30 秒收到的遥测；尚未实现历史回放。无数据时不生成演示曲线。
- 两种场景顶部均提供「RUN 自动起摆」和「停止摆控」，车载页另有「停止小车」，两者分别作用于对应设备。RUN 与设置中的起摆共用一次提交和状态条件；Host 继续核对零点、PID 及启动保护。顶部另列起摆请求结果，接受不等于实际起摆。设置保留抓零、清除 F01/F07、九项 PID、两段起摆参数与 SA21 配置。操作结果保留请求 ID，区分等待 ACK、等待读回、确认、拒绝及结果未知；超时不重发。
- 主页面手势区提供开关、最近识别、该事件请求接受／拒绝以及真实摆控状态。SG21／SA21 沿用右滑起摆、平衡后顺／逆时针正／反一圈、左滑取消参考和挥手停止；途中取消后再转圈先STOP并重新起摆／平衡。SP24使用前述上滑起摆与定位/取消语义，另显传感器ready及接管状态。接受不等于实际动作完成，各版独立STOP均保留。

场景组件 `frontend/src/DigitalTwin3D.vue` 与页面布局独立；显示标定不改写遥测或控制。角度页与 PWM 页分别按设备时间去重、保留各自本机到达时间；读取同一 Host 快照不会复制波形点，分页也不会为其他通道制造缺口。页超过 2 秒未更新时清空其读数，断开、切换 Host 会话或设备时间回退时清除旧采样。1 ms / 10 ms 是控制周期；Host 的分页观测刷新率较低，不能当作同频采集。

SA21／SP24 提供模式0关闭 / 1实际采用 / 2影子、独立积分开关及配置JSON导入。模板按匹配版本下载；实际采用须补齐合格Ku/Tu与误差尺度，来源及数值由原Host筛选；SP24本包工程候选仅影子资格。导入后保持关闭，不自动RUN；只有真正BALANCE后才会采用。状态和实际Q24增益保留各自采样时刻，不拼接成同一时刻快照。自适应仅作用于位置外环，实机负重效果尚未验证。

摆杆使用用户提供的 `L型摆臂(1).STEP`，保留安装孔及端部折边，转换为本地 GLB 后加载。以轴端直径 7 mm 孔的中心作为显示转轴，等比适配原场景的摆杆高度；底盘和旋臂仍为示意模型，并非完整装配的实物尺寸模型。移除了原先悬在摆杆上方的平衡装饰环。原件与转换方法见 `frontend/model-sources/README.md`。

显示标定按 SG21／SA21 分别保存到浏览器 v2 配置，不自动套用旧固件 v1 的两点拉伸；旧配置仍保留。SG21 采用用户于 2026-10-15 确认的自然下垂读数 -182.138° 作为本机模型参考，只添加线性显示偏移，保留真实角度尺度；SA21 没有这次实测参考，默认保持名义 ±180° 下垂。机台重新安装或读数参考改变后，在实物自然下垂并静止时点击模型右上角「下垂对齐」，即可按当前读数校准模型；仅在停止状态且有新摆角读数时可用。专家两点显示标定、方向、偏移与原插值仍可在姿态标定中设置。所有显示校准均不改变左侧原始读数、波形、PID、自适应或硬件零点，也不会发送设备命令。

## 小车 BLE 遥控

更新代码后须关闭旧的 `J280 Showcase Backend` 和 `J280 Showcase Frontend` 窗口，再运行 `START_SHOWCASE.bat`；只刷新网页不会重新加载 Python 后台。启动前会检查 8000／5173 端口，已有服务时停止本次启动；网页服务也不会自动换到 5174。若页面提示「后台未加载小车接口（404）」，说明正在运行的后台缺少 `/car` 接口，应先完成上述重启；配套 SG21／SA21 Host 窗口可保留。服务恢复后仍需手动搜索、选择、连接及启用小车。

实物为 WH-BLE102；采用用户 2026-10-11 交付的 `BLUETOOTH_HOLD_V2` 与原始 Python 驱动，不加载包内 CPython 3.14 扩展。已有工程需向实际启动后端的 Python 环境安装更新后的 `backend/requirements.txt`（新增 `bleak==3.0.2`）。有 `.venv` 时可执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
```

1. 小车电池供电、电脑蓝牙打开，切换「车载遥控台」。日常控制无需 USB 或重新配置 MAXPUT。
2. 点击「搜索小车」，手动选择 WH-BLE 102，再点击「连接小车」。后端核对 GATT、当前固件身份与本次停车反馈；不会自动选车、连接、重连或运动。
3. 手动「启用遥控」，先向左／向右打方向，再前进／后退。按钮可按住操作，键盘支持 WASD／方向键；前轮舵机负责转向，后轮电机驱动，不作原地差速旋转。协议力度保持原值，无额外力度滑块或转向锁定。
4. 松开行驶输入，停止并回正；屏幕中间 STOP、空格或 Esc 也可停止小车。显式 STOP、失焦、隐藏页面、切换场景、打开参数设置后需重新启用遥控。普通松开停车确认后可继续按住操作，仍按住的旧输入被抑制到释放。
5. 已验证的遥控连接与实际 CAR2 反馈分开判断。无新反馈时收起读数，不凭命令生成车速、位移、轮子旋转或转向动画。停车撤去驱动，车辆可能滑行，没有新增机械刹车。

输入租约为 0.2 秒；网页停止刷新输入后，后端停车并要求新的中性输入。协议原有 KEEP／固件租约、流校验、已知电机故障停车确认及未知异常断开继续使用；确认停车后轮换控制 token，旧请求不能恢复动作。页面关闭或进程突然终止时仍需依靠原固件租约，离线验证不代表实际无线时延与停车距离已验收。连接或停车所需的协议读回不可由 UI 状态代替。

## 没有实车时

按上述步骤启动页面，可查看完整模型和设置布局。未启动配套 Host、未连接串口或未收到遥测时，读数和波形保持空态。当前页面没有小车模拟动作，不生成演示曲线。

`CarControlPanel.vue` 负责显式连接，`CarControlPad.vue` 与 `useCarControl.js` 负责按住输入和取消。旧版 `carSimulation.js`、`useCarPresentation.js` 保留但当前页面不调用。底盘保持固定示意；带摆负载转弯、实物方向、停车与无线断流仍需人工实机验收。倒立摆无线遥测与网页烧录属于后续扩展。

前端验证（在 `frontend` 目录）：

```sh
node --test tests/*.test.js
npm run build
```

## 安全

后端验证：在项目根目录运行 `.venv\Scripts\python.exe -B -m unittest discover -s backend`，或使用已安装依赖的 `python`。配套 Host 来源与哈希见 `host/README.md`。

网页动作经对应 Host 原有 CRC、身份、会话、停止与读回保护处理。断开串口不等于停止电机；挥手识别保留约 1 秒等待，不能替代 STOP 或板上急停。数字测试、构建和原包内部时序记录均不能代替实机验收。本次适配未连接 COM/JTAG、烧录、驱动电机或写 Flash。
现场演示仍必须保持旋臂运动范围内无人、无线材和杂物。
