# V8.3 控制与配置约定

身份 `OK STATUS RC83`，能力 `CAPS 83 90 500 200`，启动横幅 `CAR_REMOTE_V83`。主机拒绝RC82、RC8等旧身份/CAPS/banner，撤销ready/identified；在已有连接内重新验证，不重放动作、不自动ARM或恢复快速档。

## 速度与线协议

所有手动D与八条T轨迹的持续上限：普通档1536 Q8（6计数/5 ms），快速档4096 Q8（16）。正常/快速持续PWM4200/6720，周期8400。手动B仍直行专用、最高6144 Q8（24）、最长250 ms、90% PWM；轨迹6/7在快速档快段起始可用250 ms加速增强，但幅值不超过4096。

| 命令 | 作用 |
| --- | --- |
| `T <seq> <route> <speed> <slow>` | 启动1～8号轨迹；speed/slow是Q8，均128～当前档位上限，slow≤speed |
| `U <seq> <speed> <slow>` | 更新正在运行轨迹的快/慢目标并续租，不重启路线或阶段 |
| `K <seq>` | 参数不变时续租 |

兼容直接测试用的省略slow的T时，慢段默认max(128, speed/2)。新版主机始终发送完整T/U。主机slow_percent仅允许25/50/75，先按已确认档位限制speed，再计算max(128, round(speed×percent/100))并限制slow≤speed。

T/U使用单LF结束。最长正文 `T 65535 8 4096 4096` 为19字节，加LF总长20，适配现有BLE单次写入预算。无线命令缓存20字节容纳19字节正文和NUL，超长/嵌入NUL仍按原拒绝路径处理。有效U与D/T/K一样静默，错误仍返回。序号有效性、500 ms租约和错误处理保持原规则。

U不改变route_started、阶段起点、硬截止或boost截止。正常完成后迟到的U/K只确认，不重新激活动作。主机100 ms周期检查最新意图：参数变化发送U，否则K，不积压过时更新。所有取消动作均撤销意图；完成后不自动重复。

## 轨迹时序和转向

1/2号700/800固定转向，规划8秒。3号约4秒换侧，4号约2秒换侧，切换点前后合计800 ms线性插值；相邻20 ms规划增量≤5。8号保留730～770原平缓序列。上述运行中的受控小转向允许在6/16速度下更新，不再要求速度≤3或编码器quiet；初始准备和意外大转向仍停车后到位。

5号两段各2秒行驶；每次减速至ramped=0且编码器quiet后，继续保持500 ms再进入下一段或完成。6号慢1500 ms、快3000 ms、慢1500 ms、减速至静止结束。7号慢1000 ms、快2500 ms、原最长150 ms制动。硬截止：5号20000 ms，6号12000 ms，7号9650 ms，其余14000 ms。U不重置上述截止。

每次手动舵机目标变化（包括≤5计数微调）仍进入原停车准备；舵机5计数/20 ms步进、到位稳定至少200 ms后，再按正常16 Q8/5 ms斜坡恢复速度。轨迹名称只描述时间/转向规划，不代表位置、航向或距离闭环。

## 反馈

CAR8文本字段数/顺序、二进制20字节A8/8A帧头和CRC16不变。tag低6位为序号，bit6为aux；主帧bit7是舵机高位、byte15是servo−500低8位，aux的bit7必须为0。电子舵机范围500～1000。

原requested_q8线字段在RC83改为 `car_effective_target(s)`：停止、转向准备或制动时0，有效boost时受限峰值，其余为当前受限阶段目标。内部CarState.requested_q8仍可记录阶段请求；模拟器另存内部请求，不能使用反馈字段倒推请求。ramped_q8仍为加减速后的目标。窗口分别显示“当前目标”和“渐变目标”，另列左右编码器计数（每5 ms）。这些数值不应标注为m/s。

## F8与配置

鼠标按住与F8按住运行是独立输入来源。F8运行时可用鼠标调整速度/慢段比例，鼠标离开路线按钮不取消F8。松开、窗口焦点丢失、STOP、断链/故障、切换轨迹后撤销意图，必须新一次释放/按下才能重新启动；键盘自动重复不能绕过此规则。

默认左620、中750、右980；左右行程130/230独立按10～100%比例缩放。100%=620/980，50%=685/865。正式配置 `%LOCALAPPDATA%\SmartCarSteeringV8\steering_limits.json`，schema/原子保存不变。有效配置优先，无文件默认620/980，坏配置提示后回退。测试隔离LOCALAPPDATA，不写正式配置。

## 标定与保护

C1仅停车且无故障可进入标定锁；期间ARM/D/T/U/K/B均以ERR CALIBRATING拒绝，PERF不绕过锁。S仍允许用于标定。C0停止回中并清锁，STOP/BRAKE保留原清锁行为；退出标定不自动运动，不写持久Flash。

保留500 ms租约、看门狗、堵转、停车回中、150 ms制动、250 ms单次boost。真实断链重连用户选定设备；同一连接中的运行错误不主动断开GATT，重新握手、STOP和停车反馈确认后才恢复操作资格，不自动ARM、恢复动作或快速档。
